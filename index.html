Concept

A multi-agent decision-making system. The user describes a hard situation. 6 autonomous agents debate over several rounds, each with its own personality, beliefs (BDI) and dedicated LLM. The goal: get the user out of an indecision loop by making their gains, losses, blockers and energy cost visible, then force a clear decision.

Système multi-agents de prise de décision. L'utilisateur décrit une situation difficile. 6 agents autonomes débattent en plusieurs tours, chacun avec sa personnalité, ses croyances (BDI) et son LLM dédié. L'objectif : sortir l'utilisateur d'une boucle d'indécision en rendant visibles ses gains, pertes, blocages et coût énergétique, puis forcer une décision claire.

What it isn't: not an oracle, not a therapist, not a passive chatbot. The Judge never says "it depends". It picks a side and owns it.

Ce que le système n'est pas : pas un oracle, pas un thérapeute, pas un chatbot passif. Le Judge ne dit jamais « ça dépend ». Il choisit un camp et l'assume.

FIPA Contract Net protocolProtocole FIPA Contract Net
CFP→ PROPOSE ×5→ ACCEPT / REJECT→ REFORMULATE→ VERDICT

Each agent implements the BDI model: Beliefs (situation, sentiment, history, constraints), Desires (permanent system prompt), Intentions (response recomputed every round). The Judge sends a CFP, evaluates each PROPOSE with an LLM and answers ACCEPT or REJECT. Rejected agents reformulate, then the Judge delivers a structured final verdict.

Chaque agent implémente le modèle BDI : Beliefs (situation, sentiment, historique, contraintes), Desires (system prompt permanent), Intentions (réponse recalculée à chaque tour). Le Judge envoie un CFP, évalue chaque PROPOSE via LLM, ACCEPT ou REJECT, les agents rejetés reformulent, puis le Judge rend un verdict final structuré.

Concept

A local autonomous agent that replaces the hosted Hugging Face API with its own OpenAI-compatible Flask server. Qwen2.5-7B-Instruct runs in 4-bit NF4 on an RTX 4060 (~5.5 GB VRAM). The agent can open apps, type code live in VS Code, search the web, and generate .docx / .pptx / .xlsx files.

Agent autonome local qui remplace l'API hébergée Hugging Face par son propre serveur Flask compatible OpenAI. Qwen2.5-7B-Instruct tourne en 4-bit NF4 sur RTX 4060 (~5.5 Go VRAM). L'agent peut ouvrir des apps, taper du code en direct dans VS Code, chercher sur le web, générer des .docx / .pptx / .xlsx.

Architecture
main.py→ agent.py→ llm_server.py (Flask)→ Qwen2.5-7B GPU

Function calling goes through Qwen's native chat template: the model answers in <tool_call>...</tool_call> blocks, which the server converts back to the OpenAI format. No magic library.

Le function calling passe par le chat template natif de Qwen : le modèle répond en blocs <tool_call>...</tool_call> que le serveur reconvertit au format OpenAI. Pas de bibliothèque magique.
